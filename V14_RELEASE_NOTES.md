# VeloRent V14 — Real Vehicle Images + Brand/Login Redesign

## Visible updates
- New VeloRent V-mark treatment throughout login and workspace logo lockups.
- Redesigned login layout with a compact admin sign-in card and a larger real-car / map cinematic image panel.
- Added local vehicle image assets for cars, bikes, scooters, vans, and trucks to the Vehicles gallery cards.
- Preserved existing page structure, login form IDs, JavaScript authentication flow, Apps Script file, Netlify function, and current Google Sheets integration files.
- Responsive layout and reduced-motion support retained.

## Deploy
1. Extract this ZIP.
2. Open `VeloRent_Premium_V4` in Visual Studio Code.
3. Deploy the folder to the existing Netlify site.
4. Keep the current Apps Script deployment and `GAS_WEB_APP_URL` environment variable unchanged.
5. Hard-refresh the website with Ctrl+Shift+R.

## Important
Vehicle gallery images are illustrative local assets, not photographs uploaded for each specific registered vehicle. The login map is cinematic artwork, not live GPS tracking. Verify login, vehicle gallery, and Google Sheets sync after deployment.
