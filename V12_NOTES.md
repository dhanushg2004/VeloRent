# VeloRent V12 — Cinematic Real-Car Map Login

## Visible changes
- Larger photographic vehicle-and-map hero panel using `assets/real-car-map-scene.webp`.
- More compact executive login card with glass-style treatment.
- Responsive single-column layout on tablets and phones.
- Subtle entrance motion and button hover feedback.
- Reduced-motion accessibility support.

## Deploy
Deploy the contents of this folder to the existing Netlify site. Keep the existing Apps Script deployment, Google Sheet, and `GAS_WEB_APP_URL` environment variable unchanged. Test sign-in after deployment.

The map image is decorative artwork, not live GPS data.
