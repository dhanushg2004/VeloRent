# VeloRent Premium V10

This is a visual polish update layered onto the V9 project. It does not add a real GPS map or a true 3D vehicle model; the hero vehicle and route remain CSS illustrations/animations. Existing backend files are retained.

## Deploy
1. Extract the ZIP.
2. Open `VeloRent_Premium_V4` in Visual Studio Code.
3. Deploy the project to your existing Netlify site.
4. Keep the existing `GAS_WEB_APP_URL` environment variable and Apps Script deployment unchanged.
5. Hard refresh with Ctrl+Shift+R and test login, vehicle list, bookings, and printing.

Visual and JavaScript syntax checks do not replace live end-to-end testing.
